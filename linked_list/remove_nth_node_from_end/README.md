# Remove Nth Node From End of List

**Difficulty:** medium  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)


## Problem Statement

Given the head of a linked list, remove the nth node from the end of the list and return its head.


## Approach

Using 2 pointers with a gap of n between them. curr pointer starts from the dummy node that points to the head, the end pointer starts from the head and then is incremented by n steps. Then iterate that pointer till it reaches the end, this leaves the curr pointer at the node before the one that needs to be removed. Break the link pointing to that node and then return dummy.next this handles the edge case where the head is removed.


## Solution

```python

from typing import Optional


# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

        
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        
        dummy = ListNode(0,head)

        curr = dummy
        end = head

        for i in range(n):
            end  = end.next

        while end:
            curr = curr.next
            end = end.next

        curr.next = curr.next.next

        return dummy.next

```
