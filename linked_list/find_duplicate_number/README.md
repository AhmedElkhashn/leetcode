# Find the Duplicate Number

**Difficulty:** medium  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/find-the-duplicate-number/)


## Problem Statement

Given an array of integers nums containing n + 1 integers where each integer is in the range [1, n] inclusive.

There is only one repeated number in nums, return this repeated number.

You must solve the problem without modifying the array nums and using only constant extra space.


## Approach

Using floyd's algorithm to detect a linked list cycle by treating the array as a linked list. we use two pointer one slow i and a faster pointer j until they meet at the same point. To find the start of the cycle which is where the duplicate is we start another slow pointer k from 0 and then loop till i & k meet and return the value. 


## Solution

```python
from typing import List


class Solution:
    def findDuplicate(self, nums: List[int]) -> int:

        i, j, k = 0, 0, 0

        while True:

            i = nums[i]
            j = nums[nums[j]]

            if i == j:
                break

        while True:

            i = nums[i]
            k = nums[k]

            if i == k:
                return k 
        
```
