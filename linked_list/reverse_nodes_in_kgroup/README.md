# Reverse Nodes in k-Group

**Difficulty:** hard  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/reverse-nodes-in-k-group/)


## Problem Statement

Given the head of a linked list, reverse the nodes of the list k at a time, and return the modified list.

k is a positive integer and is less than or equal to the length of the linked list. If the number of nodes is not a multiple of k then left-out nodes, in the end, should remain as it is.

You may not alter the values in the list's nodes, only nodes themselves may be changed.


## Approach

Reverse the list in chunks of k nodes at a time. groupPrev tracks the node just before the current group. At the start of each iteration call getKth to find the kth node from groupPrev, if it doesn't exist there aren't enough nodes left to form a full group so you break. groupNext saves the node after the group so you know where to stop and where the next group starts. Then you reverse the k nodes in place using the standard algorithm. After reversing, kth is now the head of the group and tmp (the original first node) is now the tail. You wire groupPrev.next to kth to connect the previous group to the newly reversed one, then advance groupPrev to tmp to set up for the next iteration.


## Solution

```python
from typing import Optional



# Definition for singly-linked list..
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

        
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        
        
        dummy = ListNode(0,head)
        groupPrev = dummy

        while True:
            kth = self.getKth(k,groupPrev)

            if not kth:
                break
        
            groupNext = kth.next

            prev = kth.next
            curr = groupPrev.next

            while curr != groupNext:
                tmp = curr.next
                curr.next =  prev
                prev = curr
                curr = tmp

            tmp = groupPrev.next
            groupPrev.next = kth
            groupPrev = tmp

        return dummy.next
        



    def getKth(self,k,curr):
        while curr and k > 0:
            curr = curr.next
            k-=1

        return curr

```
