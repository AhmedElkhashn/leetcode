# Linked List Cycle

**Difficulty:** easy  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/linked-list-cycle/)


## Problem Statement

Given head, the head of a linked list, determine if the linked list has a cycle in it.

There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the next pointer. Internally, pos is used to denote the index of the node that tail's next pointer is connected to. Note that pos is not passed as a parameter.

Return true if there is a cycle in the linked list. Otherwise, return false.


## Approach

Two pointers starting at the head, i moves one step at a time and j moves two steps at a time. If there is a cycle, j will eventually lap i and they will meet at the same node. If there is no cycle, j will reach the end of the list and the while loop exits.


## Solution

```python
from typing import Optional

# Definition for singly-linked list.

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:

        i = head
        j = head

        while j and j.next:
            
            i = i.next
            j = j.next.next
            
            if i == j:
                return True



        return False
        
```
