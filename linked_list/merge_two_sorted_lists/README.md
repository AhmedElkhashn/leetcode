# Merge Two Sorted Lists

**Difficulty:** easy  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/merge-two-sorted-lists/)


## Problem Statement

You are given the heads of two sorted linked lists list1 and list2.

Merge the two lists into one sorted list. The list should be made by splicing together the nodes of the first two lists.

Return the head of the merged linked list.


## Approach

Iterate while both lists have nodes remaining, comparing the current values of each. The smaller value gets appended to tail. Append whichever lis has remaining values to the end.


## Solution

```python
from typing import Optional


# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        head = ListNode()
        tail = head

        while list1 and list2:
            if list1.val < list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next

            tail  =  tail.next

        if list1:
            tail.next = list1
        elif list2:
            tail.next = list2

        return head.next
```
