# Add Two Numbers

**Difficulty:** medium  
**Topic:** Linked List  
**Link:** [LeetCode](https://leetcode.com/problems/add-two-numbers/)


## Problem Statement

You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.


## Approach

we iterate over until there are no values left in the lists or there is no carry, we calculate the sum and the carry and append the new node each iteration. 


## Solution

```python
from typing import Optional



# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next




class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:

        dummy = ListNode(None,None)
        cur = dummy
        carry = 0
        
        while l1 or l2 or carry:

            v1 = l1.val if l1 else 0
            v2 = l2.val if l2 else 0
            
            sum = v1 + v2 + carry
            carry = sum // 10
            sum = sum % 10

            cur.next = ListNode(sum,None)

            l1  = l1.next if l1 else None
            l2 = l2.next if l2 else None
            cur = cur.next

        return dummy.next
```
