# 3Sum

**Difficulty:** medium  
**Topic:** Two Pointers  
**Link:** [LeetCode](https://leetcode.com/problems/3sum/)


## Problem Statement

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.


## Approach

We sort the array then iterate over it, and then for each iteration it becomes a 2sum problem and we use a similar approach as explained [here](../two_sum_2/README.md)


## Solution

```python
from typing import List


class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:

        nums.sort()

        output = []
        

        for i, n in enumerate(nums):

            if i > 0 and n == nums[i - 1]:
                continue

            j,k = i + 1, len(nums) - 1

            while j < k:
                sum  = n + nums[j] + nums[k] 

                if sum > 0:
                    k -= 1
                elif sum < 0:
                    j += 1 
                else:
                    output.append([n,nums[j],nums[k]])  
                    j += 1
                    while nums[j] == nums [j - 1] and j < k:
                        j += 1

        return output
  
```
