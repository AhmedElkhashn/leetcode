# Trapping Rain Water

**Difficulty:** hard  
**Topic:** Two Pointers  
**Link:** [LeetCode](https://leetcode.com/problems/example/)


## Problem Statement

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.


## Approach

In a single position the water level is minimum between the tallest bar to its right and the tallest bar to its left, since the water would spill over the shorter bar. You then subtract the height at that position to get the water that can be held there. Using two pointers at opposite ends of the array we calculate it and increment towards the one that is shorter side its the limiting factor. 


## Solution

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
                
        area = 0 
        l, r = 0, len(height) -1
        maxLeft = height[l]
        maxRight = height[r]   

        while l < r:
            if maxLeft < maxRight:
                l += 1
                maxLeft = max(maxLeft, height[l])
                area += maxLeft - height[l]
            else:
                r -= 1
                maxRight = max(maxRight, height[r])
                area += maxRight - height[r]

        return area 
```
