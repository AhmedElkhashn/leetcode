# Binary Search

## Problem Statement

Given an array of integers nums which is sorted in ascending order, and an integer target, write a function to search target in nums. If target exists, then return its index. Otherwise, return -1.

You must write an algorithm with O(log n) runtime complexity.


## Approach

Using to pointers calculate the midpoint of the array, if the values of the target is larger than the value at the midpoint we shift the left pointer to the midpoint, if the value of the target is smaller we shift the right pointer to the midpoint otherwise it must be equal to the target so we return the midpoint.


## Solution

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        
        l, r = 0, len(nums) - 1

        while l <= r:

            midpoint = l + (( r - l ) // 2)

            if target > nums[midpoint]:
                l = midpoint + 1
            elif target < nums[midpoint]:
                r = midpoint - 1
            else:
                return midpoint


        return -1
```
